  \begin{block}{Abstract}
 
Counterdiabatic Hamiltonian Monte Carlo (CHMC) combines the principles of counterdiabatic driving from quantum control theory with Sequential Monte Carlo (SMC) methods to enable efficient sampling from complex probability distributions. By learning a gauge potential that compensates for the non-equilibrium effects of time-varying Hamiltonians, CHMC achieves faster convergence and better exploration compared to standard HMC methods. This poster presents the theoretical foundations and practical implementation of CHMC.

  \end{block}

  \begin{block}{Hamiltonian Dynamics}

Hamiltonian dynamics describe the evolution of a physical system in terms of position $q \in \mathbb{R}^d$ and momentum $p \in \mathbb{R}^d$ coordinates. The dynamics are governed by a \emph{Hamiltonian} function $H(q,p)$ through Hamilton's equations:

\begin{align}
\dot{q} &= \frac{\partial H}{\partial p} \\
\dot{p} &= -\frac{\partial H}{\partial q}
\end{align}

The Hamiltonian typically decomposes as $H(q,p) = T(p) + V(q)$, where $T(p) = \frac{1}{2}|p|^2$ is the kinetic energy and $V(q)$ is the potential energy. The flow $\phi_H^t$ generated by these equations preserves the Hamiltonian: $H(\phi_H^t(q,p)) = H(q,p)$ for all $t$.

  \begin{block}{Statistical Mechanics \& Equilibrium}

In statistical mechanics, a system in thermal equilibrium at inverse temperature $\beta$ has a probability distribution over phase space given by the \emph{canonical ensemble}:

\begin{equation}
\rho_H(q,p) = \frac{1}{Z} e^{-\beta H(q,p)}
\end{equation}

where $Z = \int e^{-\beta H(q,p)} dq dp$ is the partition function. For $\beta=1$, this becomes $\rho_H(q,p) \propto e^{-H(q,p)}$.

The key property is that Hamiltonian dynamics preserve this equilibrium distribution: if $(q,p) \sim \rho_H$, then $\phi_H^t(q,p) \sim \rho_H$ for all $t$. This makes Hamiltonian dynamics ideal for MCMC sampling, as the marginal distribution on $q$ is $\pi(q) \propto \int e^{-H(q,p)} dp = e^{-V(q)}$.

  \end{block}

  \begin{block}{Counterdiabatic Gauge Potential}

When the Hamiltonian depends on time through a parameter $\lambda(t)$, we have $H(\lambda(t))$. The naive approach of following the time-dependent Hamiltonian flow $\phi_{H(\lambda(t))}$ fails because:

\begin{equation}
\partial_t \rho_{H(\lambda(t))} = \{H, \rho_{H(\lambda(t))}\} + \dot{\lambda} \partial_\lambda \rho_{H(\lambda(t))} \neq 0
\end{equation}

The distribution \emph{lags behind} the changing Hamiltonian. The \emph{counterdiabatic gauge potential} $A(q,p)$ solves this by satisfying:

\begin{equation}
\{A, H\} = \partial_\lambda H - \langle \partial_\lambda H \rangle
\end{equation}

where $\{A, H\} = \frac{\partial A}{\partial q} \frac{\partial H}{\partial p} - \frac{\partial A}{\partial p} \frac{\partial H}{\partial q}$ is the Poisson bracket. Using the modified Hamiltonian $H_c = H + \dot{\lambda} A$, the flow $\phi_{H_c}^t$ perfectly preserves the time-varying equilibrium: $\phi_{H_c}^t \rho_{H(\lambda(t))} = \rho_{H(\lambda(t+t'))}$.

\begin{block}{Sequential Monte Carlo}

Sequential Monte Carlo (SMC) methods sample from a target distribution $\pi_1$ by constructing a sequence of intermediate distributions $\pi_{\lambda}$ for $\lambda \in [0,1]$, where $\pi_0$ is easy to sample from and $\pi_1$ is the target.

At each step $k$, we:
\begin{enumerate}
\item Evolve particles using a Markov kernel $K_{\lambda_k}$ that targets $\pi_{\lambda_k}$
\item Compute importance weights: $w_i^{(k)} \propto w_i^{(k-1)} \frac{\pi_{\lambda_{k+1}}(x_i)}{\pi_{\lambda_k}(x_i)}$
\item Resample when effective sample size (ESS) drops below a threshold
\end{enumerate}

The key challenge is designing kernels $K_\lambda$ that efficiently transport particles between distributions. Standard HMC kernels require many steps to equilibrate, leading to slow mixing.

\begin{block}{SMC with Learned Transport Map}

Instead of using generic MCMC kernels, we can learn a \emph{transport map} that directly transforms particles from $\pi_{\lambda_k}$ to $\pi_{\lambda_{k+1}}$. This is more efficient but requires:
\begin{itemize}
\item A parameterized family of maps $T_\phi(x; \lambda)$
\item A loss function to learn $\phi$ that measures how well $T_\phi$ transports the distribution
\item Samples from the current distribution to train on
\end{itemize}

Counterdiabatic driving provides a natural transport map: the flow $\phi_{H_c}^t$ generated by $H_c = H + \dot{\lambda} A$ exactly transports $\rho_{H(\lambda(t))}$ to $\rho_{H(\lambda(t+\Delta t))}$. The gauge potential $A$ acts as the learned transport map, parameterized by an ansatz $A_\phi(q,p)$.

\begin{column}{\colwidth}

\begin{block}{Counterdiabatic Hamiltonian Monte Carlo}

\textbf{Learning the Gauge Potential:} At each SMC step with parameter $\lambda_k$, we learn $A_\phi$ by minimizing:

\begin{equation}
\mathcal{L}(A_\phi) = \mathbb{E}_{(q,p) \sim \rho_{H(\lambda_k)}} \left[ \left( \{A_\phi, H\} - \partial_\lambda H + \langle \partial_\lambda H \rangle \right)^2 \right]
\end{equation}

This is done using gradient descent on samples from the current distribution, with $A_\phi$ parameterized as a polynomial or neural network.

\textbf{The CHMC Algorithm:}
\begin{enumerate}
\item Initialize particles from $\pi_0$
\item For each $\lambda_k$ in schedule:
   \begin{itemize}
   \item Fit $A_\phi$ using current particles
   \item Evolve particles using $H_c = H(\lambda_k) + \dot{\lambda}_k A_\phi$ via leapfrog integrator
   \item Compute importance weights
   \item Resample if ESS drops
   \end{itemize}
\item Return final particles from $\pi_1$
\end{enumerate}

\textbf{Key Advantages:}
\begin{itemize}
\item Faster convergence: counterdiabatic driving eliminates lag
\item Better exploration: learned transport adapts to distribution geometry
\item Preserves Hamiltonian structure: maintains volume preservation
\end{itemize}
